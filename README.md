# SoraChat

iPad・スマホ向けのチャットアプリです。LINE に近い見た目と操作で、トーク（1対1・グループ）、友だち、リアクション、返信、24時間ノート、プロフィールを備えます。データベースは Supabase のみを使い、Supabase Auth は使いません。

## 機能

- ログイン：仙人アカウントで続行、またはユーザー名とパスワードで登録・ログイン
- 画面：下のタブで「トーク」「友だち」「その他」を切り替えます
- トーク：1対1とグループ（テキスト・画像・ファイル・連絡先、リアクション 👍 ❤️ 😂 😮 😢 🙏）
- 友だち：ユーザー名の検索かQRコードで追加します。友だちの削除もできます
- グループ：友だちの中から選んで作成・メンバー追加します（友だち以外は入れられません）。管理者が名前変更・メンバー削除、全員が退出
- 新規トーク：友だちを選んで1対1で話す、またはグループを作成
- ノート：60文字まで、24時間で消える一言。相手のプロフィールに表示
- 返信・メニュー：吹き出しをダブルタップするとメニューが開きます（返信・コピー・編集・送信・取り消し）。返信は入力欄の上に返信先を出し、吹き出しの上に引用を表示します
- 通知：新着トークのWeb Push（オン・オフ可）。画面を見ている間は出さず、裏に回したときや閉じているときに届きます
- プロフィール：LINE風（背景の色、アバター、ステータスメッセージ、ノート、QRコード）
- アニメーション：画面の切り替え、シート、吹き出しの出現、ハートの浮き上がり、タブ、未読バッジなどに動きを付けています（端末の「動きを減らす」設定では最小限になります）

## サーバー負荷について

- 新着はポーリングせず、Supabase Realtime（postgres_changes）で受け取ります。
- 送信・リアクション・メンバー操作だけがAPIリクエストになります。
- 未読などの一覧は、イベントを受けたときにまとめて再取得します（連続イベントは0.4秒まとめます）。保険として2分ごとにも再取得します。

## セットアップ

1. Supabase の SQL Editor で次の順に実行します（どれも再実行して問題ありません）。
   - `supabase/schema.sql`
   - `supabase/schema_v2.sql`
   - `supabase/schema_v3.sql`（プロフィールの連絡先・Web サイト）
   - `supabase/schema_v4.sql`（編集・送信取り消し・転送）
   - `supabase/schema_v5.sql`（送信の重複防止・過去ログの読み込み）
   - `supabase/schema_v6.sql`（ファイル添付・連絡先の送信）
   - `supabase/schema_v7.sql`（友だち・プロフィールの背景。既存の1対1の相手は自動で友だちになります）
   - `supabase/schema_v8.sql`（返信機能）
   - `supabase/schema_v9.sql`（グループのアイコン画像）
   - `supabase/schema_v10.sql`（オープンチャット・利用停止）
2. Supabase の Realtime が有効になっていることを確認します（既定で有効です）。
3. `.env.example` を `.env` にコピーして値を入れます。
   - `SUPABASE_URL` / `SUPABASE_SERVICE_ROLE_KEY` / `SUPABASE_ANON_KEY` / `SUPABASE_JWT_SECRET`（Settings → API にあります）は必須です。
   - 仙人アカウントは `SENNIN_*`、通知は VAPID キーを設定します。
4. `npm install` のあと、開発は `npm run dev`、本番は `npm run build` → `npm start` です。

## オープンチャット・管理者パネル

- オープンチャット：「その他」→「オープンチャット」から、誰でも一覧を見て参加できるグループを作れます（友だちでなくても参加可能）。
- 管理者パネル：`/admin/login` から `ADMIN_PASSWORD` でログインします。一般の画面には入口を出していません。
  - ユーザーの一覧・検索、詳細ページ、利用停止（BAN）と解除、管理者からの友だち追加（誰とでも可）
  - 全チャットの一覧と閲覧（送信・編集はできません）
  - 利用停止にすると、そのユーザーはログインできず、既存のログインも切れます。
- 管理者のログインは12時間で切れます。パスワードを忘れた場合は環境変数 `ADMIN_PASSWORD` を変えてください。

## Render へのデプロイ

- Build Command: `npm install && npm run build`
- Start Command: `npm start`
- Health Check Path: `/api/health`
- 環境変数は `.env.example` と同じ名前で設定します。

## 注意点

- iOS で通知を受けるには、Safari でホーム画面に追加して、そのアプリとして開く必要があります。通知の許可は、設定のスイッチを押した直後に求めます。
- 通知の購読は、アプリを開くたびに確かめ直します（許可済みの端末のみ）。
- 通知がオフのときは「通知をオンにしますか？」を出します（「あとで」を押すと3日間は出しません）。
- グループのアイコンは管理者だけが変更できます（名前の変更と同じ条件）。
- ログイン試行は1分あたり20回までに制限しています。この制限はプロセス内の記録なので、複数インスタンスでは共有されません。
- ロゴとアイコンは SoraLink の流用です。`public/icons/icon-180.png` を差し替えてください。
- 旧版（DMだけのバージョン）の既存データは、そのまま使えます。schema_v2 は既存テーブルに列を追加するだけです。


## UI update notes

- 画面は LINE のトークの見た目に合わせています（`src/styles.css`）。自分の吹き出しは黄緑、相手は白で、背景は LINE の定番の青みがかったグレーです。時刻と既読は吹き出しの外に出し、グループでは送った人の名前を表示します。
- 友だちは `sc_friends` テーブルで管理し、相互に友だちになります。グループの作成とメンバー追加は、友だちを選ぶ形になります（サーバーでも友だち以外は拒否します）。
- プロフィールの背景は 6 色から選べます（`sc_users.cover_theme`）。
- ライトテーマを初期設定にし、設定からライト / ダークを切り替えられます。選択したテーマはブラウザーに保存されます。
- ロゴとアイコン、配色は LINE の公式素材ではなく、見た目を似せて作った独自のものです。
- Font Awesome は CDN から読み込みます。QR コードは端末の中で生成します。
