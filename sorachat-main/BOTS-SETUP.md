# Bots（Groq無料AI）セットアップ — v2

## 追加されたもの
- server/bots.ts ：/bots の配信、会話（ストリーム）、過去のチャット、再生成、返信案の送信、SoraChat連携
- server/index.ts ：bots ルーターの登録（1行・変更なし）
- public/bots.html ：Bots の画面。SoraChat の画面からはリンクしていません
- supabase/schema_bots.sql ：連携の許可を保存する表（v1）
- supabase/schema_bots_v2.sql ：過去のチャットを保存する表（v2）

## 手順
1. Supabase の SQL Editor で次を順に実行
   - supabase/schema_bots.sql（まだの場合）
   - supabase/schema_bots_v2.sql
2. Groq（https://console.groq.com）で無料のAPIキーを発行
3. 環境変数を設定
   - GROQ_API_KEY=gsk_...
   - GROQ_MODEL=（任意。空でもよい。使えないモデルは自動で次の候補に切り替わります）
   - MESSAGE_ENCRYPTION_KEY は既存のものを使います（過去のチャットの保存に使う暗号化の鍵）
4. npm install && npm run build && npm start
5. https://（サーバー）/bots を開く（SoraChat にログインした状態で）

## 機能
- **SoraChat の会話を読む**：連携を許可すると、AIが「トークを読む必要があるか」を判断します。必要なときだけ、本人が参加しているトークの直近の内容（最大2件・各15件）を読みます。どのトークを読んだかは画面に「〇〇とのトーク」として表示されます。
- **返信案**：「〇〇に返信して」と頼むと、返信文を作ります。送信は、画面で内容を確認して「送信」を押したときだけ行われます。AIが勝手に送ることはありません。
- **思考の過程**：AIの考え中の内容をリアルタイムに表示します（モデルが対応している場合）。回答が始まると自動で畳まれ、「思考の過程」から開けます。
- **過去のチャット**：左の履歴から開けます。削除も可能です。会話は暗号化して保存されます。
- **コピー・編集・再生成**：メッセージをダブルクリック（スマホは長押し、PCは右クリック）でメニューを開き、コピーや編集ができます。編集すると、その後の返答はやり直されます。AIの最後の返答は「再生成」できます。

## 注意（プライバシー）
- トークを読んだときは、その内容（相手の発言を含む）が Groq（外部のAIサービス）に送られます。連携はいつでも設定からオフにできます。
- パスワードや、本人が参加していない会話は AI に渡しません。
- 本人がその画面から消したメッセージ（sc_message_hides）は読みません。
- 投資は、AIが実際のお金を自動で売買しない設計です。情報提供と一般的な注意に留めています。

## 無料枠の制限
- Groq の無料枠には、1分あたりのトークン数の上限があります。読む量を控えめにしていますが、混み合うと「AIが混み合っています」と表示されます。少し待ってから再度お試しください。
- 上限に達すると「AIが応答できませんでした」と表示されることがあります。

## トラブルシューティング
- 「AIの設定に問題があります」と出る：GROQ_API_KEY が無効です（サーバーのログに Groq API key rejected と出ます）。キーを作り直し、前後の空白や改行がないか確認してください。変更後はサーバーを再起動してください。
- 「SoraChat と連携してください」と出る：ロック画面の「SoraChat と連携する」を押してください。
- 過去のチャットが出ない：schema_bots_v2.sql が実行されているか確認してください。
- 思考の過程が出ない：モデルによっては思考を返さない場合があります。その場合は表示されません（回答は通常どおり出ます）。
